# StoreAutomatization — Система автоматизації роботи магазину

Консольний застосунок на **C# (.NET 10)** для автоматизації касових операцій, складського обліку та контролю доступу персоналу магазину. Проєкт розроблено за принципами багаторівневої архітектури (*Layers*), об'єктно-орієнтованого проєктування та UML-моделювання.

---

## Основний функціонал

* **Рольова модель доступу (RBAC):** розмежування прав між ролями `Guest`, `Cashier` (відкриття, наповнення, оплата та скасування чеків) та `Admin` (додавання нових товарів, перегляд детальної звітності).
* **Життєвий цикл чека (State Machine):** суворий контроль переходів між станами `Open` $\rightarrow$ `Paid` та `Open` $\rightarrow$ `Canceled` із блокуванням повторної оплати, зміни закритих чеків або оплати порожнього чека.
* **Складський облік:** автоматичне резервування та списання товарів при скануванні в чек, перевірка залишків на складі та **автоматичне повернення товарів на баланс** при скасуванні непорожнього чека.
* **Фінансові розрахунки:** підрахунок загальної суми чека (`GetTotal()`), перевірка достатності внесеної готівки та розрахунок решти.
* **Журналювання подій:** наскрізне логування всіх дій користувачів, помилок валідації та винятків за допомогою **Serilog**.

## Архітектура та структура проєкту

Проєкт побудовано за шаблоном **Layers** із дотриманням принципу **Model-View Separation** та інверсії залежностей (**Dependency Inversion**):

```text
StoreAutomatization/
├── UI/                         # Рівень представлення (Presentation Layer)
│   └── StoreConsoleUI.cs       # Сценарії взаємодії з користувачем (працює через IStoreService)
├── Services/                   # Бізнес-рівень (Business Logic Layer)
│   ├── IStoreService.cs        # Контракт бізнес-операцій
│   └── StoreService.cs         # Реалізація бізнес-логіки, валідацій та RBAC
├── Repositories/               # Рівень доступу до даних (Data Access Layer)
│   ├── IStoreRepository.cs     # Контракт сховища даних
│   └── StoreRepository.cs      # Реалізація in-memory сховища
├── Data/                       # Ініціалізація даних
│   └── MockData.cs             # Початкове наповнення каталогу категорій, товарів та чеків
├── Models/                     # Доменна модель (Domain Model)
│   ├── BaseEntity.cs           # Абстрактний базовий клас сутностей (id)
│   ├── Category.cs             # Категорія товарів
│   ├── Product.cs              # Товар (складський залишок, ціна, характеристики)
│   ├── ProductInfo.cs          # Детальна інформація про товар (композиція)
│   ├── Receipt.cs              # Фіскальний чек та автомат станів
│   ├── ReceiptItem.cs          # Позиція в чеку (композиція)
│   └── ReceiptState.cs         # Перелік станів чека (Open, Paid, Canceled)
├── Infrastructure/             # Наскрізна функціональність (Cross-Cutting Concerns)
│   ├── Security/
│   │   ├── SecurityManager.cs  # Аутентифікація та керування поточною роллю
│   │   └── UserRole.cs         # Перелік ролей користувачів
│   └── Logging/
│       └── Logger.cs           # Обгортка над Serilog для консольного логування
├── Program.cs                  # Точка входу (Composition Root)
└── StoreAutomatization.csproj  # Конфігурація проєкту та залежностей NuGet
```

## Технологічний стек

* **Мова та платформа:** C# / .NET 10.0
* **Бібліотеки:** `Serilog`, `Serilog.Sinks.Console`
* **Інструменти моделювання:** UML (діаграми прецедентів, активностей, станів, послідовностей, пакетів та класів)

## Запуск проєкту

1. Клонуйте репозиторій та перейдіть у каталог проєкту:
   ```bash
   git clone <url-вашого-репозиторію>
   cd StoreAutomatization
   ```
2. Відновіть залежності та запустіть застосунок:
   ```bash
   dotnet restore
   dotnet run
   ```

### Тестові облікові записи
* **Адміністратор:** логін `admin`, пароль `admin123`
* **Касир:** логін `cashier`, пароль `cashier123`
